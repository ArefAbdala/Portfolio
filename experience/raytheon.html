Role Overview

Served as a Systems Engineering Intern at Raytheon Intelligence & Space, supporting the Joint Polar Satellite System Common Ground System (JPSS CGS) program. Focused on process improvement, documentation infrastructure, and data quality initiatives using Atlassian tools.

JPSS Common Ground System

The Joint Polar Satellite System (JPSS) Common Ground System is the end-to-end ground infrastructure supporting NOAA's polar-orbiting weather satellite constellation. The CGS processes environmental data products supporting weather forecasting, climate monitoring, and disaster response operations.

Tools & Processes

  • Atlassian Jira — custom dashboards, smart filters, and workflow automation
  • Atlassian Confluence — knowledge base and desk instruction documentation
  • Employee directory — self-auditing organizational tool for program accountability
  • Data quality framework — structured process for identifying and resolving data discrepancies
